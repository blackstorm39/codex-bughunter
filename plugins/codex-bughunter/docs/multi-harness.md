# Codex integration

Version 2.1.1 is a Codex-only fork. It does not install files into other agent
harnesses and does not read `~/.claude.json`.

The supported interfaces are:

- Codex plugin skills for model-driven workflows.
- `cbh` for deterministic terminal operations.
- `codex exec` for optional headless hunt and validation phases.
- Codex MCP configuration for an explicitly supplied Burp transport.

See [installation](../INSTALL.md) for the native marketplace commands.
